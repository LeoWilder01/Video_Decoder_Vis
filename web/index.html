Forward trace / 真实中间激活

z → Clamp → Conv → MemBlock → 空间 / 时间扩张 → RGB → clamp[0,1] → 裁去最前 3 帧。点击操作查看真实计算结果；展开 MemBlock 可进入其内部卷积和激活。

MemBlock：当前特征与上一时间位置的特征拼接，经三层卷积后加回当前特征。权重固定，变化的是这里的激活。中间的 t 使用该层自己的时间网格，不能直接当作输入 latent 的 t。
